# 八卦炉 SDD 验收记录

- 验收基线：`docs/proxy-pool-sdd.md`
- 验收日期：2026-08-29
- 本地环境：macOS；OpenWrt 实机项目单独列出

## 已通过的自动化项目

- Go 格式化、静态检查、全量单元与 HTTP 集成测试。
- React/TypeScript 类型检查与 Vite 生产构建。
- Mihomo 配置、控制 API、节点链路证据、流量增长和进程回收测试。
- 上游刷新失败保留旧节点；订阅节点消失后删除其测量历史；手动节点不受订阅刷新影响。
- API Key 分组隔离、订阅 Token、格式限制、UA 自动适配、ETag 和各输出格式契约。
- 评分公式、基础设施样本排除、单线程队列、取消和任务清理。
- 单文件 1000 行门禁与 OpenWrt init shell 语法检查。

## 本轮修复

- Ping 默认周期改为 1 分钟；下载测速按本地自然日执行一次，并在允许时段内运行。
- 支持多个测速源，同一自然日批次稳定使用同一来源；测速源异常不计入节点评分。
- 测量记录补齐测试地址、协议、测速源、外网基线、WAN 前后计数、背景上下行、配置带宽、负载状态、采样时长、有效下载时长和 Mihomo 证据。
- 基础设施失败不再触发评分重算；Ping 或吞吐成功不再错误恢复节点，只有协议连通性成功恢复节点。
- 同入口 IP 连续出现明确网络层不可达后统一熔断；协议或认证失败只影响当前节点；冷却后仅代表节点可恢复整组。
- 启动时清除未知活动任务，任务 API 只返回受支持且正在处理的任务；基础设施暂停结果进入终态，不再永久堆积为活动任务。
- Mihomo 启动失败进入 `failed/degraded`，测试提交返回稳定错误；手动停止可取消待执行的自动重启。
- 主程序处理 SIGTERM/SIGINT，先关闭 HTTP，再回收受管 Mihomo；管理端口绑定失败写入 LuCI 状态文件。
- LuCI 启用状态写入独立 UCI；配置提交和生命周期操作使用 ubus；状态页展示期望状态、实际状态、PID、端口、Mihomo 和最近错误。
- 管理后台新增只读系统设置页、节点搜索与筛选、单节点三类测试、完整测速证据展开项，并保持 Ant Design 明亮模式。
- 订阅缓存 `Last-Modified` 改为节点数据更新时间，不再每次请求生成当前时间。

## 需要 OpenWrt 实机完成的系统验收

- 安装、启用、禁用、开机启动、手动停止、异常拉起、升级保留配置和卸载清理。
- ubus/procd 在目标 OpenWrt 版本上的 `service.set` 返回结构与异步状态轮询。
- OpenClash 正在运行时的安装、启动、测速、停止、升级和卸载共存回归。
- 目标架构 Mihomo 包、全部协议真实配置加载、控制端口/代理端口冲突和连续崩溃阈值。
- WAN 接口识别、真实 5 秒计数采样、上传突发、负载未知和竞争流量排除。
- Clash Verge、OpenClash、Nikki、v2rayNG、PassWall、SSR+、sing-box、dae/daed 的真实客户端导入。

上述项目依赖 OpenWrt、OpenClash、目标架构 Mihomo 和真实客户端，不能由当前 macOS 环境可信替代。
